# Employee Excellence Dashboard

### Power BI | Employee Performance Analytics

## Project Overview

The Employee Excellence Dashboard is an interactive Power BI project designed to analyze employee performance, monitor monthly rankings, and recognize outstanding employees across departments.

The dashboard demonstrates how employee evaluation data can be transformed into meaningful insights to support performance monitoring and recognition decisions.

## Key Features

- Monthly employee performance analysis
- Department-based performance filtering
- Weighted performance scoring
- Employee ranking based on evaluation results
- Employee of the Month recognition
- Interactive data visualization

## Evaluation Criteria

The demonstration model uses six weighted performance metrics:

| Metric | Weight |
|---|---:|
| Performance / KPI | 30% |
| Attendance | 20% |
| Task Completion | 20% |
| Quality | 15% |
| Teamwork | 10% |
| Manager Evaluation | 5% |
